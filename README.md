# SwiftUI Projects 📱

A collection of iOS applications and projects built using **Swift and SwiftUI**. This repository documents my journey of learning SwiftUI, exploring Apple's development frameworks, and building practical iOS applications.

## 🚀 Projects

This repository contains SwiftUI projects ranging from beginner-friendly applications to more advanced app development experiments.

Each project focuses on learning new concepts, improving UI design skills, and understanding how to build native iOS applications.

## 🛠️ Tech Stack

- Language: Swift
- Framework: SwiftUI
- IDE: Xcode
- Platform: iOS

## 📂 Repository Structure

```text
SwiftUI-Projects/
├── AppOne/
├── AppTwo/
├── AppThree/
└── README.md
```

Each app is maintained in its own folder and may include its Xcode project, source code, assets, and other required resources.

## 🎯 Goals

- Build practical iOS applications using SwiftUI.
- Understand SwiftUI layouts, views, and modifiers.
- Explore state management and navigation.
- Create reusable and maintainable UI components.
- Learn Apple's frameworks through hands-on projects.
- Gradually develop more complete, real-world applications.

## ▶️ Getting Started

1. Clone the repository.
2. Open the desired Xcode project.
3. Select an iOS simulator or compatible device.
4. Build and run the application using **⌘ + R**.

Check each project's requirements for the appropriate Xcode and iOS SDK versions.
